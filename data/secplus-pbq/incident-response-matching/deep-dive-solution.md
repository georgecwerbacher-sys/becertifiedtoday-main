# Incident response matching — solution walkthrough

## Preparation

Before incidents: **develop the IR plan** and **train roles** so the team knows who does what when an event occurs.

## Identification

During detection: **analyze logs/alerts** for anomalies and **validate/categorize** whether events are true security incidents.

## Containment

Limit damage: **segment the network** or apply short-term fixes and **isolate affected systems** so malware or attackers cannot spread.

## Eradication

Remove the threat: **delete malware/artifacts** and **disable compromised accounts** so attacker access cannot persist.

## Recovery

Return to business: **restore from clean backups** and **monitor/validate** that systems behave normally again.

## Lessons Learned

After closure: **update the IR plan and controls** and run a **post-incident review** with root-cause analysis to improve future response.
