# Network protocols matching — solution walkthrough

Drag each protocol from the bank into the slot beside its security function. Every protocol is used once.

| Protocol | Role |
|----------|------|
| **WPA2** | Wi‑Fi Protected Access 2 — AES-based wireless encryption |
| **IPSec** | Network-layer IP packet encryption and integrity (AH/ESP) |
| **PGP** | Pretty Good Privacy — asymmetric encryption for files/email |
| **SSL** | Legacy Secure Sockets Layer for HTTPS; superseded by TLS |
| **RADIUS** | Remote Authentication Dial-In User Service — centralized AAA |
| **VPN** | Virtual private network — encrypted tunnel for remote access |
| **Kerberos** | Ticket-granting authentication in Windows/AD environments |
| **TLS** | Transport Layer Security — modern HTTPS web encryption |
| **S/MIME** | Secure/Multipurpose Internet Mail Extensions — signed/encrypted email |
| **SSH** | Secure Shell — encrypted remote administration and SCP/SFTP |
| **802.1X** | Port-based network access control (NAC) with EAP authentication |

Common distractors: SSL vs TLS (legacy vs current web), PGP vs S/MIME (both email, different standards), VPN vs IPSec (VPN often uses IPSec but the tunnel description maps to VPN as a service).
