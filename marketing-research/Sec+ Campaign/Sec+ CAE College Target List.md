## 60-mile radius targeting

For the `secplus_workforce_us` campaign, target **students and educators within a 60-mile radius** of each priority school campus or service area.

**Google Ads setup:**

1. Campaign: `Security+ SY0-701 · Student Workforce · US`
2. Locations → Advanced search → Radius
3. Enter each school campus city/address
4. Set radius to **60 miles**
5. Location option remains **Presence** — people in or regularly in targeted locations
6. Keep campaign language as English

**Use:** Start with the highest-priority 10–15 schools if the location list is too large to build in one sitting, then add the rest after the first review.

**Do not:** Use school names in ad copy until the Security+ mapping is verified on official school pages.
