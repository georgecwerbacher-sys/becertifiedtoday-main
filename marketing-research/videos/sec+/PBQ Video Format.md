# PBQ video format

Add this section structure on top of [[../Production Template|Production Template]] and [[../_video-template|_video-template]] for every Security+ PBQ video.

**Primary focus:** [[PBQ Video Strategy]]

---

## Section timings (default 5–6 min)

| Time | Section | Shot | Content |
|------|---------|------|---------|
| **0:00–0:15** | Hook | A-roll | “After your Security+ course — this is how I practice **[PBQ type]** before test day.” |
| **0:15–0:45** | PBQ type frame | A-roll + lower third | Name scenario · chain / DnD / ordering / hot spot · **prep**, not lesson |
| **0:45–1:15** | Read the prompt | Screen | Scroll exhibit · show multi-part tabs · **what to scan first** |
| **1:15–3:30** | Technique demo | Screen + VO | Work **one part** or pattern — explain *approach*, not full spoiler bank |
| **3:30–4:00** | Common mistake | A-roll or screen | One wrong instinct · why it fails on exam-style items |
| **4:00–4:20** | Mid CTA | Lower third | “Pause — try the **free sample** on Be Certified Today.” |
| **4:20–5:00** | Recap | A-roll | 3 bullet technique summary |
| **5:00–5:20** | Outro CTA | End card | Tagline + `comptia-sec+-home.html` UTM |

**Short (60–90 s):** Hook + one technique moment + “Full prep on the site” + tagline.

---

## On-screen labels (Premiere)

Use step labels, not domain chapter titles:

- `Step 1 — Read all parts first`
- `Step 2 — Map zones before dragging`
- `Step 3 — Flag and move on if stuck`

---

## Screen recording rules

- [ ] URL is **sample** path when scenario is in [[PBQ Video Strategy#UTM pattern|free bundle]]
- [ ] Hide paid-only chain sections if not in sample
- [ ] No answers pasted in lower thirds
- [ ] Zoom 125% · cursor highlight on drag targets
- [ ] If chain lab: show **sidebar / Next** — teaches exam pacing

---

## Title formula

```
How I Practice Security+ PBQs: [Scenario Hook] | SY0-701 Prep
```

Short:

```
PBQ Tip: [One technique] | Security+ Prep
```

```
Security+ SY0-701 PBQ prep — practice technique, not a full course.

Independent prep — not affiliated with CompTIA.
```
