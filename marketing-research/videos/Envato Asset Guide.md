# Envato Elements — asset guide

Use your **[Envato Elements](https://elements.envato.com/)** subscription for licensed motion, music, and SFX. **Do not commit login URLs or tokens** to this repo — bookmark Elements in your browser only.

Align assets with **prep / exam practice** tone — not flashy course-intro energy. See [[Production Template]].

---

## What to download (by use)

| Use | Search on Elements | Notes |
|-----|-------------------|-------|
| **End card** | `minimal tech lower third logo reveal` | Recolor to `#2f66bf` · 3–5 s |
| **Lower third** | `corporate lower third clean` | Name + `Try free samples →` |
| **Transition** | `smooth slide transition pack` | Subtle — avoid gaming wipes |
| **Background loop** | `abstract technology dark blue` | Behind A-roll at 20% opacity |
| **Music bed** | `corporate ambient tech minimal` | No vocals · steady · −20 dB under voice |
| **SFX** | `soft whoosh` · `mouse click` · `keyboard typing` | Screen demo sections only |
| **Stock B-roll** | `developer laptop office` | When not showing portal |
| **Icons** | `cyber security line icons` | Sec+ thumbnails only — not in exam content |

---

## License hygiene

For each project folder:

1. Download asset → save **license certificate PDF** from Elements
2. Path: `Videos/Assets/[slug]/envato-licenses/`
3. Note asset name + URL in video brief **Envato / asset** column

Elements license covers YouTube and website embed when subscriber at download time.

---

## Brand fit — avoid

| Skip | Why |
|------|-----|
| Loud **course-style** intros (10 s+ logo explosions) | Conflicts with “not a bootcamp” positioning |
| **Guaranteed pass** stock graphics | Policy / trust risk |
| **Exam dump** / brain imagery | Wrong audience signal |
| Heavy **epic trailer** music | Feels like Udemy course ad |

---

## Suggested starter pack (download once)

Save to `Videos/Assets/_shared/`:

- [ ] 1 × minimal **end card / logo sting** (3 s)
- [ ] 1 × **lower third** mogrt (Premiere)
- [ ] 2 × **music** tracks (main + Short)
- [ ] 1 × **transition** pack (8–12 subtle cuts)
- [ ] **Inter** font files if not installed (thumbnail/end card)

---

## Premiere import

| Asset type | Import as |
|------------|-----------|
| `.mogrt` | Essential Graphics panel → drag to V3 |
| `.mp4` loop | V1 background · loop · opacity 15–25% |
| `.wav` music | A2 · Essential Sound → Music |
| `.mp3` SFX | A3 |
