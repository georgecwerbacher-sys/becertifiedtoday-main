# Wedge Marketing Plan

**Problem:** Head terms (CCNA practice test`, `mock exam`, `question bank`) are bid up by course vendors using free samples as loss leaders. You cannot sustainably win top-of-page on those queries.

**Strategy:** Own **wedge keywords** where your product is uniquely strong — browser labs, timed simulation, exam readiness — and target people **2–3 weeks from test day**.

**Canonical voice:** [[../Site Mission|Site Mission]] — *Practice like test day. Walk in ready.*

**Why we pivoted (narrative):** [[00-why-ccna-marketing-changed|CCNA]] · [[secplus-wedge-campaign/00-why-marketing-changed|Security+]]

## Quick reference — your wedge (not theirs)

| They sell | You sell |
|-----------|----------|
| Free samples → $300–$2,000 course | **$9.99 / 10-day exam sprint** |
| 10,000 static questions | **Timed sim + drag-drop + CLI labs in browser** |
| GNS3 / Packet Tracer / IOU | **No install — labs in the testing engine** |
| PDF / dump / forum votes | **Verified explanations (v1.1 & v2.0)** |
| Big bank, random order | **Review loops weak topics** |
