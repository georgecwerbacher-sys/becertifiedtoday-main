List Rooms

List rooms.

The title of the room for 1:1 rooms will be the display name of the other person.

By default, lists rooms to which the authenticated user belongs. Long result sets are split into pages.

GET /v1/rooms

Name Description
teamId
string		 List rooms associated with a team, by ID.
type
string		 List rooms by type. Possible values: direct, group.
sortBy
string		 Sort results. Possible values: id, lastactivity, created.
max
number		 Limit the maximum number of rooms in the response. Default: 100.
