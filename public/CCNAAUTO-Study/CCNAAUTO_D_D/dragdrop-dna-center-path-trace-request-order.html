On a phone or tablet, tap a chip to pick it up, then tap a drop zone (or another chip to swap).

Drag and drop the requests from the left into the correct order on the right to create and check the path trace between two devices using the Cisco DNA Center API.

Requests

GET /dna/intent/api/v1/network-device
GET /dna/intent/api/v1/flow-analysis/{flowAnalysisId}
POST /dna/system/api/v1/auth/token
POST /dna/intent/api/v1/flow-analysis

Correct order

1. Authenticate and obtain an API token.

2. Retrieve device details or IP addresses used for the trace.

3. Initiate a new path trace with source and destination IP values.

4. Check the path trace result using the returned flow analysis ID.
