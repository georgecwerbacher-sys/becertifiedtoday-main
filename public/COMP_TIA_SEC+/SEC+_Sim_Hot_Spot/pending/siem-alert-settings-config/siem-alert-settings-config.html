SIEM Alert Settings

Configure the SIEM alert settings based on the ticket from your manager.

Ticket #983981

Suspicious repeated login attempts have been observed. Corporate policy allows no more than five invalid login attempts within a 15-minute window. Use any recommended settings offered by the console.

When the threshold is exceeded, trigger an alert and email the security team at security@example.com.

The new SIEM is not yet integrated with source firewalls — configure alert/notify only, not blocking.

Use both tabs: Rule Settings and Action Preferences.

SIEM alert console

Rule Settings

Window Types

Choose how login failures are tracked over time:

  • Static: Count resets every fixed interval (e.g., every 15 minutes on the clock).
  • Repeated Interval: A new window starts after each detection.
  • Sliding (Recommended): Continuously checks the most recent X minutes — most accurate for burst detection.

Action Preferences

Notification Options

Choose how you want to be notified when the threshold is reached:

  • Email: Sends an alert to the specified email address.
  • SMS: Sends a text message to a mobile number with country code.
  • Dashboard Alert: Displays an alert in the admin dashboard (no address required).
  • Push notification: Sends to a mobile app or browser.
  • Microsoft Teams / Slack Channel: Posts via webhook URL.
